# Data implementation decisions

These decisions supplement the project ADR log. Evidence is linked in [data-sources.md](data-sources.md). Date: 2026-10-08 KST.

1. **Coverage is gated by evidence.** Enable ECB EURUSD, the explicitly derived ECB USDJPY and official Treasury 10Y. The other eleven indicators are configured but disabled with individual reasons. `return_only` is not treated as a workaround for unverified retrieval or derived-data rights. A source being enabled means its configured feed is usable subject to run-time freshness gates, not that every future run will succeed.
2. **Unknown publication timestamps remain null.** Official feed receipt confirms availability at fetch time. No scheduled clock time is substituted for a provider publication timestamp. Historical feeds may contain revisions; simulations are not a live record, and no observation can prove its past availability without archived vintage evidence. Revisions belong in append-only corrections, not changed actuals.
3. **Calendar event versus publication is explicit.** ECB uses 16:00 Europe/Berlin on TARGET days as its daily reference event convention. Treasury uses 15:30 America/New_York, capped at SIFMA's early close. Treasury's source documentation does not promise the specification's 17:00 publication time. The latest-source check remains authoritative for availability.
4. **Calendar libraries and exceptions are pinned and tested.** XKRX/XNYS use exchange_calendars; Treasury uses pandas_market_calendars SIFMA_US. NYSE DST and early closes, Korean Lunar New Year/Chuseok/substitute holidays, ECB TARGET days and SIFMA Columbus/Veterans holidays are tested. SIFMA's current page confirms a noon Good Friday close in 2026. Scheduled calendar rules still require monitoring for emergency closures and future changes. Commodity and Korean bond/FX placeholder calendars are not approved series definitions.
5. **Bitcoin is a proxy.** Retain the requested stable ID `btcusd` for API compatibility, but label it Bitcoin / USDT (USD proxy). Use the 22:00 opening hourly candle and map its inclusive final millisecond to the exact 23:00 boundary. The source remains disabled pending rights verification.
6. **The minimum counts model observations.** Models consume changes. `min_history: 300` therefore requires at least 301 consecutive levels; otherwise only 299 changes could satisfy the spec's level-count reading. Gaps in the used context cause `history_gap`; no filling or multi-session changes are silently inserted.
7. **Transforms are unit-safe.** Percent-quoted yields use `100 × difference` to obtain basis points; inverses divide changes by 100. Price-like inputs must be positive. Non-finite, duplicate, unsorted, naive-timestamp and explicitly preliminary inputs are rejected. Future closes and known future publications never enter context.
8. **Local evidence stays outside the repository.** Raw bytes and immutable metadata sidecars store SHA-256, UTC receipt time and redacted URLs. API keys are environment-only and excluded from fingerprints. Three bounded retries follow the required delays; stale cache data never replaces a failed live request. Windows trust is supplemented by certifi without weakening HTTPS verification.

Unresolved before broad activation: ECOS credentials and source-specific rights/timing; vendor decisions for SPX, NASDAQ, WTI and gold; Cboe permission; Binance applicable redistribution terms; actual operational latency measurements; source-specific revision monitoring and manual correction validation. A 365-day baseline/calendar simulation validates only the implemented subset and cannot satisfy the full TSFM shadow-backtest or public-live requirements.
