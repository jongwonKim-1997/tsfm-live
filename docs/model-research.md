## APIs and output semantics

- **Chronos-2:** `Chronos2Pipeline.from_pretrained(repo, revision=sha, device_map=...)`; `predict_quantiles([1D_tensor], prediction_length=1, quantile_levels=model.quantiles, cross_learning=False)`. Result is a list of tensors shaped `(variates, horizon, quantiles)`. The package's second returned value is its median even though named `mean`; benchmark `mean` is null. [Official package](https://pypi.org/project/chronos-forecasting/2.3.2/), [source](https://github.com/amazon-science/chronos-forecasting).
- **Chronos-Bolt:** `BaseChronosPipeline.from_pretrained`; native-grid `predict_quantiles(1D_tensor, prediction_length=1)` returns `(batch, horizon, quantiles)`. Its so-called `mean` is likewise median and omitted. Both Chronos wrappers clamp out-of-range quantiles internally, so adapters request only native quantiles and perform the required linear tail extrapolation themselves. [Official package](https://pypi.org/project/chronos-forecasting/2.3.2/).
- **TimesFM:** `TimesFM_2p5_200M_torch.from_pretrained(..., torch_compile=False)` and `compile(ForecastConfig(..., use_continuous_quantile_head=True))`, then `forecast(horizon=1, inputs=[array])`. The full head is `(batch,horizon,10)`: channel 0 is mean; channels 1–9 are deciles. The first tuple return is median, not mean. Nonnegative-input output clipping is disabled because the target is a signed transformed change. [Official package](https://pypi.org/project/timesfm/3.0.2/), [source](https://github.com/google-research/timesfm).
- **Moirai 2.0:** `Moirai2Module.from_pretrained` and `Moirai2Forecast(module=..., prediction_length=1, target_dim=1, feat_dynamic_real_dim=0, past_feat_dynamic_real_dim=0, context_length=n)`. Native `predict([array])` returns `(batch,quantiles,horizon)` for the univariate runtime (the target dimension is squeezed despite the general docstring); native levels come from `module.quantile_levels`. The 2.0 model is quantile-based, not a sample model. [Official package](https://pypi.org/project/uni2ts/2.0.0/), [source](https://github.com/SalesforceAIResearch/uni2ts).
- **Toto:** the official distribution is **`toto-ts`**, not the unrelated PyPI package `toto`. `Toto.from_pretrained`, `MaskedTimeseries`, and `TotoForecaster(model.model).forecast(..., prediction_length=1, num_samples=1000, samples_per_batch=50)`. Samples are `(batch,variate,horizon,samples)` and converted to empirical quantiles. Dummy timestamps contain no real calendar features and the interval is one synthetic session. [Official package](https://pypi.org/project/toto-ts/0.2.0/), [source](https://github.com/DataDog/toto).
- **TiRex:** the official distribution is **`tirex-ts`**. `load_model(repo, backend='torch', device='cpu', compile=False, hf_kwargs={'revision':sha, ...})` forwards the exact pin. `forecast(..., output_type='numpy')` returns `(batch,horizon,quantiles)` and a median labelled mean; the adapter omits that mean. Current source supports a pure Torch CPU backend. The vendor reports tests on Linux/macOS; Windows is not vendor-validated. [Official package](https://pypi.org/project/tirex-ts/1.4.2/), [source](https://github.com/NX-AI/tirex).
- **Sundial:** `AutoModelForCausalLM.from_pretrained(..., trust_remote_code=True, revision=sha, code_revision=sha)` followed by `generate(tensor[None,:], max_new_tokens=1, num_samples=50)`. Twenty batches produce 1000 samples. Its official card pins Transformers 4.40.1; that pin cannot share Chronos's dependency environment. [Pinned official model source](https://huggingface.co/thuml/sundial-base-128m/tree/3212e42564493f520593e5414af4367fc4b49226).
- **TabPFN-TS:** verified `TabPFNTSPipeline(tabpfn_mode=TabPFNMode.LOCAL, ...)` and `predict_df(..., prediction_length=1, quantiles=...)`. Version 1.3.0 defaults to v3.5. The model filename is `tabpfn-v3.5-20260909.safetensors`. Although HF metadata reports `gated:false`, the local `tabpfn==9.1.0` loader invokes authenticated licence acceptance. No credentials or acceptance are assumed. The optional adapter remains unimplemented and disabled; no API service is contacted. [Official package](https://pypi.org/project/tabpfn-time-series/1.3.0/), [backend](https://pypi.org/project/tabpfn/9.1.0/), [source](https://github.com/PriorLabs/tabpfn-time-series).
