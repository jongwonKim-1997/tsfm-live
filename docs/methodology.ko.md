# 평가 방법

TSFM Live는 공개 시계열 모델의 출력을 두 기준 모델과 비교합니다. 유효한
출력은 결과가 알려지기 전에 공개 저장소에 기록되어야 합니다. 빈 표는
조건을 충족하는 실시간 평가 기록이 아직 없다는 뜻입니다. 과거 시뮬레이션은
실시간 원장과 별도로 보관합니다.

## 평가 대상과 실행 시각

평가 대상은 실행 시점부터 24시간 이내에 있는 다음 거래 세션의 확정 종가입니다.
모델에는 최대 512개의 과거 변환값을 입력하며 미래 정보는 제공하지 않습니다.
최소 300개 세션의 이력이 필요합니다. 가격·지수에는
`y = 100 × ln(다음 값 / 이전 값)`을 사용합니다. 퍼센트 단위 금리는
`y = 100 × (다음 값 − 이전 값)`으로 변환해 베이시스포인트(bp)로 평가합니다.
가격 수준은 제공자의 이용 조건이 허용하는 경우에만 표시합니다.

매일 한국 시각 08:10에 실행하며, 공개 기록 마감은 08:50입니다. UTC로는
전날 23:10과 23:50입니다. 자료 지연, 비거래일, 24시간 이후의 다음 종가,
불충분한 이력, 모델 오류, 마감 지연을 각각 기록합니다. 늦은 출력을 과거의
유효한 기록으로 바꾸지 않습니다. 비트코인은 UTC 23:00에 끝나는 1시간 봉의
종가를 사용하며, 다른 지표는 휴일·조기 폐장·서머타임을 포함한 시장 달력을
따릅니다.

## 모델과 구간

기반 모델은 고정된 패키지 버전과 가중치 리비전으로 실행합니다. 이번 평가에서
관측된 결과에 맞추어 추가 학습하지 않습니다. 모델 실행이 실패했을 때 같은
모델 이름으로 기준 모델 출력을 대신 넣지 않습니다. 버전 변경과 이전 이력을
공개 기록에 남깁니다.

`rw0`의 모든 분위수는 0입니다. 비교 기준인 `volnaive`는 과거 입력에서 추정한
EWMA 변동성(`lambda = 0.94`)과 평균 0의 정규분포를 사용합니다. 앙상블은 그날
성공한 기반 모델들의 분위수별 중앙값이며 최소 세 모델이 필요합니다. 화면에는
그날 참여한 모델 수를 함께 표시합니다.

공통 분위수는 `0.025, 0.05, 0.10, 0.20, 0.30, 0.40, 0.50, 0.60, 0.70,
0.80, 0.90, 0.95, 0.975`입니다. 모델 고유 분위수인지, 표본에서 계산했는지,
보간했는지를 기록합니다. 분위수는 유한하고 오름차순이어야 합니다. 80% 구간은
0.10~0.90, 95% 구간은 0.025~0.975 분위수로 구성합니다. 개별 출력의 이 구간과
집계 성능의 신뢰구간은 서로 다른 개념입니다.

## 개별 출력 점수

중앙값으로 제곱 오차와 절대 오차를 계산합니다. 핀볼 손실은 실제 값이 분위수
이상이면 `tau × (실제 값 − 분위수)`, 그렇지 않으면
`(1 − tau) × (분위수 − 실제 값)`입니다.

주 평가지표는 **분위수로 근사한 CRPS**이며, 공통 13개 분위수의 핀볼 손실을
더해 `2 / 13`을 곱합니다. 정규분포 기준 모델도 같은 근사를 사용하고, 낮을수록
좋습니다. 표준정규분포에서 실제 값이 0이면 이 격자의 점수는 0.2111939013입니다.
연속 분포의 해석적 CRPS와 같은 값으로 취급하지 않습니다.

방향 적중은 중앙값과 실제 값의 부호가 같은지 평가합니다. 중앙값의 절댓값이
로그 변화에서는 0.01퍼센트포인트, 금리 변화에서는 1bp보다 작으면 방향을
제시하지 않은 것으로 처리하고 적중값을 비워 둡니다. 경계와 정확히 같으면
평가에 포함합니다. 실제 값 0과 0이 아닌 중앙값은 적중하지 않은 것으로 봅니다.
중앙값이 항상 0인 기준 모델에는 적중률이 없습니다. 적중률과 함께 방향을
제시한 비율·표본 수를 표시하고, 0.5를 기준으로 양측 이항검정 p값을 계산합니다.

구간 포함률은 양 끝점을 포함합니다. 구간 너비는 상단 분위수에서 하단 분위수를
뺀 값입니다. 넓은 구간만으로 좋은 평가를 받았다고 해석하지 않도록 두 값을
함께 표시합니다.

## 평가 창, 상대 성능, 순위

7d·30d·90d는 달력 일수가 아니라 지표별 최근 평가 세션 수입니다. 모든 모델에
같은 지표별 평가 날짜를 적용한 다음 변동성 상태를 나눕니다. 각 셀은 기준 모델과
겹치는 날짜만 사용합니다. `n`은 짝지어진 관측 수이며, `observed_n`은 비교 전에
존재했던 해당 모델의 관측 수입니다. 10쌍 미만의 셀은 표시할 수 없습니다.
따라서 7세션 창에서는 표본 수만 표시되고 성능 셀·등급은 비어 있습니다.

CRPS 상대 손실은 같은 날짜에서 모델 평균 손실을 기준 모델 평균 손실로 나눈
값이며, skill은 `1 − 상대 손실`입니다. RMSE도 같은 날짜를 사용합니다. 양수이면
기준보다 손실이 작고, 0이면 같으며, 음수이면 더 큽니다. 기준 손실이 0이면
비율을 정의할 수 없어 비워 둡니다. 모델 손실 자체가 0이면 임의의 작은 수를
더하지 않고 그대로 계산합니다.

전체 상대 CRPS는 유효한 지표별 상대 손실의 기하평균이며, 전체 skill은
`1 − 기하평균`입니다. 각 지표의 비중은 같습니다. 숫자 순위는 90d 또는 전체
기간에서, 활성 지표의 최소 75%에 각각 60쌍 이상이 있을 때 부여합니다.
그 외 모델은 관찰 단계로 남습니다. 기준 모델과 앙상블도 항상 표시합니다.
7d·30d에는 숫자 순위를 부여하지 않습니다.

신뢰구간은 길이 5의 순환 이동 블록을 1,000회 재표집해 계산하며 시드는 7입니다.
날짜를 지표 간에 함께 재표집해 동시 의존성과 실제 결측을 유지하고, 최초 유효
셀 집합을 고정합니다. 결과의 2.5·97.5백분위가 95% 신뢰구간입니다. 정의 가능한
재표집 결과가 95% 미만이면 신뢰구간·등급을 비워 둡니다. 하한이 양수면 A,
상한이 음수면 C, 0을 포함하면 B입니다. 다중 비교를 보정한 전체 모델 간 우열
검정은 아닙니다.

순위는 전체 skill, 같은 날 CRPS 승률 순으로 정합니다. 순위 변화는 현재 순위에서
일곱 번째 이전 실행의 순위를 뺀 값입니다. 변동성 상태는 출력 시점에 알 수 있는
EWMA 변동성과 이전 250세션 분포의 80백분위를 비교해 정합니다. 상태별 화면은
같은 평가 창을 해당 상태로 제한합니다.

## 지표 예측가능성

Predictability Index(PI)는 결과를 본 뒤 가장 좋은 모델을 고르는 편향을 줄이기
위해 앙상블의 90d 성능을 사용합니다.
`PI = 100 × clip(앙상블 CRPS skill / 0.20, 0, 1)`입니다. 음의 skill은 0,
20% 이상의 손실 개선은 100에 해당합니다. 초기 관찰 기간에는 척도를 고정하며,
허용된 이후 변경도 공개 결정 기록이 필요합니다.

PI가 5 미만이면 예측 어려움, 5 이상 20 미만이면 약함, 20 이상 50 미만이면
보통, 50 이상이면 강함입니다. 30쌍 미만은 자료 부족으로 표시하고 계산 가능한
PI도 흐리게 표시합니다. 상태별 PI 역시 해당 상태에서 30쌍이 필요합니다.
유의성은 앙상블 skill 신뢰구간 하한이 0보다 큰지로 정합니다. 표시되는 개별
최우수 모델에는 60쌍이 필요하며, 결과를 본 뒤 고른 비교임을 명시합니다.

스냅샷은 기존 기록을 바꾸지 않고 일별 순위와 PI를 보존합니다. PI 이력은
당일을 포함해 최대 180개이며 빈 값도 유지합니다. 30일 변화에는 정확히
30일 전 달력 날짜의 스냅샷이 필요합니다.

## 공개 원장과 한계

출력은 정규화된 UTF-8 JSON과 SHA-256 해시로 기록합니다. 공개 해시 색인은
해당 출력 바이트가 들어 있는 커밋을 가리킵니다. 실제 값, 점수, 실행 명세,
정정, 집계 스냅샷은 추가만 허용합니다. 정정은 원문을 고치지 않고 연결된 별도
기록으로 추가하며, 집계를 다시 만들 때 승인된 정정을 적용합니다.

결과는 대상 종가 시각 이후에 확정적으로 확보했을 때만 평가합니다. 종가로부터
5일이 지나도 확보하지 못하면 평가 불가로 기록하고 점수를 비워 둡니다.
화면은 파이프라인이 만든 JSON을 표시하며 브라우저에서 점수를 계산하지 않습니다.
공개 API도 같은 값과 표본 수를 제공합니다.

첫 공개 발표 전에는 최소 90일의 실시간 관찰 이력이 필요합니다. 과거
시뮬레이션은 실시간 기록을 대신할 수 없으며 모델 사전학습의 영향을 받을 수
있습니다. 자료 수정, 달력 정의, 모델 실패, 적은 표본은 명시적인 한계입니다.
PI와 순위는 관측된 다음 세션 평가를 요약하며 미래 결과의 확실성을 뜻하지 않습니다.
